# Studio

The official portfolio and showcase website for **SynviaTech**.

**Ideas awaken into reality.**

This project represents SynviaTech’s digital presence, highlighting our services, projects, and approach to building modern software solutions.

---

## ✨ Overview

Studio is a modern, responsive web application built with a focus on:
- Clean UI/UX
- Performance
- Scalability
- Maintainable code

It serves as both our **company portfolio** and a **foundation** for future public-facing products.

---

## 🚀 Features

- Modern responsive design (mobile → extra large screens)
- Light & dark mode support
- Clean hero-based landing experience
- Component-driven architecture
- Brand-aligned design system
- Accessible and performant UI

---

## 🛠 Tech Stack

- **Frontend:** React
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Heroicons
- **Build Tool:** Vite

---

## 🎨 Design

- Primary brand color: `#3E1444`
- Minimal, modern layout
- Tailwind utility-first styling
- Smooth transitions and hover states
